# Гласови инструкции — записи на български език

Приказният парк пуска гласови инструкции **само от предварително записани аудиофайлове**. Синтезиран глас не се използва.
Ако за някоя фраза няма запис, инструкцията се показва като текст с илюстрация, а бутонът „Чуй отново“ не се появява.

## Как се добавят записите

1. Запишете всяка фраза ясно и спокойно, с кратка пауза в началото и в края (формат MP3, моно, 44,1 kHz).
2. Поставете файловете в `public/audio/kg/bg/` — препоръчително име: `<идентификатор>.mp3`.
3. Добавете ги в `public/audio/kg/bg/manifest.json`:

```json
{
  "files": {
    "feed.intro": "feed.intro.mp3",
    "feed.give.big.1.apple": "feed.give.big.1.apple.mp3"
  }
}
```

Списъкът се зарежда при отваряне на приказния парк; не е нужна промяна в кода. Учителският панел показва колко фрази са записани.
