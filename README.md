# Математически увеселителен парк

Образователна уеб игра по математика за ученици от 2. до 4. клас. Направена е като приказен увеселителен парк с атракциони. Всеки атракцион е отделна математическа игра.

## Стартиране

```bash
npm install
npm run dev        # сървър за разработка
npm test           # тестове на математическата логика
npm run build      # production build в папка dist/
npm run preview    # преглед на production build
```

Папката `dist/` е статичен сайт, който работи без интернет: шрифтовете са вградени, а звуците се синтезират в браузъра. Сборката е настроена за адрес `/math-amusement-park/` (base path във `vite.config.ts`).

## Публикуване

Играта е публикувана на https://krgeorgieva80-crypto.github.io/math-amusement-park/

Всяка промяна в клон `main` се публикува автоматично чрез GitHub Actions (`.github/workflows/deploy.yml`). В Settings → Pages полето Source трябва да е **GitHub Actions**.

## Какво съдържа

- **Начален екран**: панорама на парка с бутоните „Играй“, „За играта“, „За учителя“ и настройки за звука.
- **Избор на клас**: 2., 3. и 4. клас.
- **Карта на парка**: осем атракциона, всеки с собствена SVG илюстрация. Засега е активен само „Вълшебните жетони“, останалите са отбелязани с „Очаквай скоро“.
- **„Вълшебните жетони“** — четири режима с разрядни жетони (1, 10, 100, 1000, 10 000):
  - **Състави числото** — разряден състав по колони (стотици, десетици, единици…); „Различни представяния“ (напр. 47 = 3 десетици и 17 единици); „С различни жетони“ (досегашната игра с жетони 1, 2, 5, 10, 20 и т.н.).
  - **Събиране** — две групи жетони се преместват в сбора; при 10 еднакви жетона се разменят за 1 от по-горния разряд.
  - **Изваждане** — от умаляемото се махат жетони; при нужда 1 жетон се разменя за 10 по-малки, включително последователно през нулите (305 − 128).
  - **Предизвикателство** — липсващо събираемо, умалител или умаляемо (с жетони), сравняване на изрази (везна), открий грешката, друг начин за същото число.
  - Настройки: клас, режим, числов обхват, без/с преминаване или смесени, трудност (Откривател/Изследовател/Майстор), 5/10/15 задачи. Показват се само приложимите.
  - Влачене с мишка и пръст или докосване; бутони „Провери“, „Изчисти“, „Помощ“, „Следваща задача“.
- **Учителски панел**: клас, трудност, брой задачи (5/10/15), подсказки, звук, музика, заключване на избора. Показва и анонимни резултати.

## Структура

```
src/
  core/          сцена и мащабиране, настройки, localStorage, звук (Web Audio)
  attractions/   регистър на атракционите
  components/    SVG илюстрации, талисман, декор, бутони и ефекти
  screens/       начален екран, клас, карта, „За играта“, „За учителя“
  games/
    magic-tokens/
      placeValue.ts   разрядно представяне и размяна на жетони
      arithmetic.ts   събиране/изваждане с преминаване, преноси, заемане през нула
      tasks.ts        режими: генериране, ограничения, проверка, подсказки
      logic.ts        „С различни жетони“ (досегашната игра)
      *.test.ts       автоматизирани тестове
```

### Добавяне на нов атракцион

1. Създайте игра в `src/games/<id>/`.
2. В `src/attractions/registry.ts` сменете `status` на `'ready'`.
3. В `src/App.tsx` изберете компонента според `screen.game`.

### Замяна на графика и звуци

- Всяка илюстрация е отделен компонент в `src/components/art/`. Може да се замени с професионално изображение (`<image href="...">`), без да се пипа останалият код.
- Звуците се синтезират в `src/core/sound.ts`. С `sound.registerSample('success', '/sounds/success.mp3')` всеки звук може да се замени с аудио файл.

## Поверителност

В `localStorage` на устройството се пазят само настройките и анонимни резултати: дата, клас, ниво и брой решени задачи. Не се събират имена или лични данни. Не се използват външни услуги.
